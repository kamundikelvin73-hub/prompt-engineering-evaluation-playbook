# Prompt Optimization Summary

## Summary

Prompt quality improves when instructions are specific, structured, and measurable.

## Best Practices

1. Specify role and audience.
2. Add constraints.
3. Require structured output.
4. Avoid vague verbs.
5. Include safety requirements where needed.
6. Make evaluation criteria explicit.

This project demonstrates prompt engineering skills relevant to AI training, LLM evaluation, content improvement, and structured data generation.
