# Prompt Refinement Case Study

## Objective

Improve a vague prompt so the AI output becomes more useful and easier to evaluate.

## Original Prompt

Explain cloud computing.

## Problems

- No target audience
- No length requirement
- No structure
- No evaluation criteria
- No use case

## Improved Prompt

You are an IT support specialist. Explain cloud computing to a beginner in under 150 words.

Include:
- Simple definition
- One real-world example
- Difference between local storage and cloud storage
- One benefit
- One risk

Use clear headings and avoid jargon.

## Expected Improvement

The improved prompt should generate a clearer, more structured, beginner-friendly answer.
