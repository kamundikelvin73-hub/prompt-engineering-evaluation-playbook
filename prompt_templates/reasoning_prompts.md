# Reasoning Prompt Templates

## Step-by-Step Reasoning

Analyze the problem step by step before recommending a solution.

Return:
1. Key facts
2. Possible causes
3. Risks
4. Recommended action

## Prioritization

Rank the tasks from highest to lowest priority and explain why.

## Root Cause Analysis

Identify possible causes without assuming certainty. Suggest what information is needed to confirm the cause.
