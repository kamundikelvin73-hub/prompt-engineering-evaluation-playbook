# Prompt Engineering Evaluation Playbook

## Overview

This repository demonstrates practical prompt engineering, prompt optimization, structured output design, and AI response evaluation workflows.

It is built for AI Trainer, Prompt Engineer, LLM Evaluator, AI Quality Analyst, and RLHF Contributor roles.

## Skills Demonstrated

- Prompt engineering
- Prompt optimization
- LLM evaluation
- Structured output design
- Rubric-based assessment
- AI safety prompting
- Professional rewriting
- Classification prompting
- Reasoning prompt design

## Core Principle

A strong prompt should clearly define the role, task, context, constraints, output format, and evaluation criteria.
