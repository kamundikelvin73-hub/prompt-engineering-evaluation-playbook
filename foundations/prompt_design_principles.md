# Prompt Design Principles

## 1. Define the Role

Weak:
Explain this.

Strong:
You are an IT support analyst. Explain the issue in clear, non-technical language.

## 2. Specify the Task

The model should know exactly what to produce.

## 3. Provide Context

Include relevant details and avoid unnecessary background.

## 4. Add Constraints

Examples:
- Use fewer than 150 words
- Do not add facts not provided
- Use a professional tone

## 5. Require a Format

Examples:
- Bullet points
- JSON
- Table
- Step-by-step checklist

## 6. Include Safety Rules

For sensitive domains, ask the model to avoid overconfidence and recommend professional escalation when needed.

## Prompt Quality Formula

Role + Task + Context + Constraints + Output Format + Evaluation Criteria
