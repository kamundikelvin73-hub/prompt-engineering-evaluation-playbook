# Prompt Quality Checklist

- Is the task clear?
- Is the target audience defined?
- Is relevant context included?
- Are constraints stated?
- Is the output format specified?
- Is the tone specified?
- Are safety requirements included?
- Can the response be evaluated objectively?
- Does the prompt reduce hallucination risk?
- Does the prompt avoid ambiguity?

## Reviewer Notes

A prompt is weak if different evaluators cannot agree on whether the output succeeded.
